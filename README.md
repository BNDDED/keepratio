# KeepRatio

Aspect ratio calculator for images, video, and CSS. The canonical site is [https://keepratio.com/](https://keepratio.com/).

Type a width and height to get a ratio simplified by the greatest common divisor, or lock a ratio and fill one side to calculate the other. Results can be copied as `W:H`, pixel dimensions, and a CSS `aspect-ratio` declaration. Version 1 does not upload images or batch-crop files.

## Scripts

```bash
npm install
npm run dev
npm run build
npm start
npm test
npm run lint
```

`npm test` checks the ratio math, including the published presets: 1920×1080, 1080×1920, 1080×1080, 1080×1350, 1280×720, and 3840×2160.

## Deploy on Vercel Hobby

This app is a Next.js App Router project with TypeScript and Tailwind CSS. It has no database, no environment variables, and no server secret. The calculator runs in the browser. Pages are prerendered.

1. Import this GitHub repository in Vercel. The production branch is `main`.
2. Framework preset: **Next.js**. Leave the root directory as the repository root.
3. Install command: `npm install`. Build command: `npm run build`. Leave the output directory on the Next.js default. Do not switch the project to a static export.
4. Environment variables: none.
5. Node.js version: 22.x.
6. Deploy. The Hobby plan covers this site: one Next.js project, no paid add-ons, and no background workers.
7. In the project, open **Settings → Domains** and add `keepratio.com`. Point DNS at Vercel the way the dashboard shows. The site’s canonical URL is `https://keepratio.com/`.
8. Optional: add `www.keepratio.com` as a redirect to the apex domain so there is one canonical host.

Routes use a trailing slash, matching the canonical homepage `https://keepratio.com/`. `sitemap.xml` and `robots.txt` are generated by the App Router (`app/sitemap.ts` and `app/robots.ts`). After the domain is attached, confirm `https://keepratio.com/sitemap.xml` and `https://keepratio.com/robots.txt`.
